## Channel Setup Steps

### 1. Create the Channel

Since Telegram bots can't create channels directly, create it manually:

1. Open Telegram → New Channel
2. Channel name: **StockAnalyst — Daily Battle Plans**
3. Username: **@StockAnalyst_channel** (if taken, try @StockAnalyst_BP or @StockAnalystBot_channel)
4. Set to **Public** channel
5. Description: `Free daily stock & crypto Battle Plans. Transparent, deterministic scoring (0-100). No AI guessing — just RSI, MACD, price change, MA alignment, and volume. Powered by @claw_analyst_bot`

### 2. Add the Bot as Admin

1. Go to Channel → Edit → Administrators → Add Administrator
2. Search for @claw_analyst_bot
3. Grant permissions: Post Messages, Edit Messages, Delete Messages
4. Enable "Post messages via the bot" so broadcasts come from the bot identity

### 3. Set Channel Photo

Use the StockAnalyst logo/branding image. If none exists yet, a clean icon with a chart + score overlay works well.

### 4. Pin the Welcome Message

Post Broadcast #1 (below) and pin it.

## Channel Growth Tips

1. **Consistency:** Post at the same time every day (suggested: 8:00 AM EST / pre-market)
2. **Quality > Quantity:** One solid Battle Plan > 5 vague signals
3. **Engage:** Respond to reactions and questions in the channel comments
4. **Cross-promote:** Link the channel from Twitter/Reddit posts
5. **Pinned message:** Keep the welcome message pinned with a clear "what this channel is" explanation
6. **Disclaimer:** Always include the financial disclaimer at the bottom of every broadcast
7. **Visual consistency:** Use the same formatting template for every Battle Plan — predictability builds trust
